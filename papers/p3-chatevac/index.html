Abstract

Pedestrian safety during emergency evacuations is crucial for urban building design. While conventional numerical simulation methods are powerful, they require extensive engineering expertise and incur high costs, time, and barriers that hinder their widespread adoption. We propose ChatEvac, a large language model (LLM)-driven intelligent agent that automates the complete evacuation assessment workflow starting from architectural floor plans. ChatEvac integrates a diffusion model to segment spatial features and evacuation nodes, a Social Force Model (SFM) for pedestrian simulation, and an LLM to coordinate the entire workflow through an interactive GUI. To combat LLM hallucinations inherent to complex engineering workflows, we introduce a three-layer defense mechanism:

Three-Layer Hallucination Defense Mechanism

  • Finite State Machine (FSM) — constrains valid LLM workflow transitions (+21.4% improvement)
  • Retrieval-Augmented Generation (RAG) — grounds outputs in authoritative building codes (+40.4% citation accuracy)
  • Human-in-the-Loop Verification — GUI checkpoints intercept residual errors at module boundaries

Experiments demonstrate that ChatEvac produces evacuation dynamics consistent with established simulation tools, while LLM-generated design suggestions remain both workflow-consistent and code-compliant — enabling non-expert users to conduct rigorous evacuation assessments from raw floor plan inputs with minimal manual intervention.
